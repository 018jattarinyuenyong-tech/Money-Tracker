# Money Tracker — V1.0 UI + Android/iOS compatibility

This build restores the original Money Tracker V1.0 interface, navigation menus, and app logic. It adds PWA metadata, app icons, install guidance, and a service worker shell for HTTPS hosting.

## Publish on GitHub Pages
Upload all files and folders in this package to the repository root and enable GitHub Pages. PWA installation and service worker require HTTPS hosting.

## Android
Open the published site in Chrome. Use “ติดตั้งแอป” when available, otherwise use the browser menu to install/add to home screen.

## iPhone/iPad
Open the published site in Safari → Share → Add to Home Screen.

## Data
This keeps the original V1.0 browser-storage behavior. Data is stored per browser/device and does not sync automatically. Export a backup before changing device or clearing browser data.
